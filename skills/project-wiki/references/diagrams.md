# 可选图表

只为更容易通过图理解的流程、状态或跨模块关系画图，一张图回答一个问题。正文继续保留条件、例外和实现依据，图不能替代业务约束。仓库阅读器支持 Mermaid 时可直接阅读源码，不因此引入图片生成运行时。

网页选择预生成时：

1. Mermaid 代码块含 `accTitle:` 与单行 `accDescr:`，标题和替代文字解释关系。
2. 生成键覆盖图源、渲染配置与显式 rendererVersion。改变渲染器版本或字体/主题配置时重新生成，不能继续认定旧图有效。
3. 生成器只写内容根的 diagrams 资源，在生成全部成功后再清理不再使用的摘要命名旧图；不删除用户手工资源。
4. 图源与 SVG 一起提交；校验检查资源与图源/配置对应，正式构建只读资源，不依赖 Chrome。
5. 服务端以图片呈现预生成 SVG，不执行任意 Markdown HTML或在客户端运行 Mermaid；受限图不放入公开目录。缩放/下载按项目实际需求选择。

Next.js 资产中附带 `render-diagrams.ts`。它需要目标项目选择安装匹配的 Mermaid CLI 和可用浏览器，并可通过 WIKI_CHROME_PATH 指定；不自动下载浏览器。该生成器面向具有 `node_modules/.bin/mmdc` 的 POSIX 开发环境，其他系统按现有工具链调整入口。它不会在普通 Wiki 检查或核心技能启用时自动运行。
